# ALQUIMIA EDITORIAL

## Corrección, verificación y diseño de portadas literarias asistidos por IA

### Proyecto Final — Generación de Prompts

**Autora:** Fernanda Barrionuevo

**Caso de estudio:** *INSECTA – Voces de un mundo invisible*

**Prueba de concepto:** aplicación de prompts de texto-texto y texto-imagen sobre un cuento ficticio protagonizado por una libélula.

---

## Descripción

ALQUIMIA EDITORIAL es una prueba de concepto que explora el uso de técnicas de generación de prompts para asistir diferentes etapas de un proceso editorial independiente.

La propuesta aborda tres necesidades principales:

1. corrección ortotipográfica;
2. verificación de información biológica incorporada en el relato;
3. generación de una propuesta visual para la portada.

La POC se desarrolla sobre un cuento ficticio titulado *El agua que recuerda*, protagonizado por una libélula.

---

## Caso de estudio

El proyecto utiliza un caso ficticio debido a que no se dispone de un manuscrito editorial real.

La obra ficticia *INSECTA – Voces de un mundo invisible* pertenece, dentro del caso de estudio, a una autora argentina nacida en Mendoza y mayor de 50 años.

El cuento y los elementos literarios utilizados en la POC fueron creados específicamente para este proyecto.

La información biológica se trata de forma independiente y se contrasta con fuentes externas.
